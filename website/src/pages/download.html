System Requirements

ความต้องการของระบบ

Windows Compatibility

  • Windows 11รองรับ (64-bit)
  • Windows 10รองรับ (64-bit)
  • สถาปัตยกรรมx64
  • Windows 32-bit / ARMไม่มีแพ็กเกจ

สิ่งที่ต้องมี

  • .NET Runtimeไม่ต้องติดตั้ง (รวมมาแล้ว)
  • สิทธิ์ผู้ดูแลระบบต้องใช้ตอนล้าง RAM
  • Microsoft RAMMapดาวน์โหลดผ่าน RAMFLOW
  • อินเทอร์เน็ตเฉพาะตอนดาวน์โหลด/อัปเดต

ตรวจสอบไฟล์

  • แหล่งไฟล์GitHub Releases
  • ตรวจความถูกต้องSHA-256
  • รายการเวอร์ชันลงนาม ECDSA P-256

ตรวจไฟล์ที่ดาวน์โหลดด้วย PowerShell: Get-FileHash .\ชื่อไฟล์ -Algorithm SHA256 แล้วเทียบกับค่า SHA-256 ด้านบน

Installation

ติดตั้งใน 3 ขั้นตอน

ดาวน์โหลด

เลือก Installer (MSI) เพื่อติดตั้งลงเครื่อง หรือ Portable (ZIP) ถ้าไม่อยากติดตั้ง

ติดตั้ง / แตกไฟล์

MSI: ดับเบิลคลิกแล้วทำตามขั้นตอน · ZIP: คลิกขวา → Extract All แล้วเปิด RAMFLOW.exe

เตรียม RAMMap

ครั้งแรก RAMFLOW จะเสนอให้ดาวน์โหลด RAMMap จากเว็บไซต์ทางการของ Microsoft หลังจากยอมรับเงื่อนไขการใช้งาน

ถ้า Windows SmartScreen แสดง “Windows protected your PC” ให้ตรวจว่าไฟล์มาจากหน้านี้และ SHA-256 ตรงกัน จากนั้นกด More info → Run anyway · อ่านเพิ่มที่ คำถามที่พบบ่อย
