Features

ทุกอย่างที่ต้องใช้ ในหน้าต่างเดียว

ออกแบบให้เข้าใจง่าย แสดงตัวเลขที่วัดได้จริง และไม่สัญญาเกินกว่าที่ Windows ทำได้

RAM Monitoring แบบเรียลไทม์

ดู RAM ที่ใช้ พร้อมใช้ แคช Standby และ Modified อัปเดตทุก 1 วินาที พร้อมกราฟ 60 วินาทีล่าสุด

ล้าง RAM ด้วยคลิกเดียว

เลือกวิธีล้างได้ 4 แบบ (Standby List, Working Sets, System Working Set, Modified Page List) ตามที่ RAMMap ในเครื่องรองรับ

Auto Clean อัจฉริยะ

ล้างตามเวลา ตามเปอร์เซ็นต์การใช้ RAM หรือเมื่อ RAM พร้อมใช้ต่ำ พร้อมขีดจำกัดความปลอดภัยในตัว

ประวัติและสถิติ

ทุกการล้างบันทึกค่าที่วัดจริงก่อน/หลัง ดูสถิติวันนี้ สัปดาห์นี้ และส่งออกเป็น CSV ได้

ตรวจลายเซ็นก่อนทำงาน

ตรวจลายเซ็นดิจิทัลของ Microsoft บน RAMMap ก่อนใช้งานทุกครั้ง และตรวจลายเซ็นกับ SHA-256 ของทุกอัปเดต

ทำงานเงียบ ๆ ที่ถาดระบบ

ย่อไปที่ System Tray เริ่มพร้อม Windows ได้ สั่งล้างจากเมนูถาดระบบ และรองรับภาษาไทย / อังกฤษ

Auto Clean

ล้างเมื่อจำเป็นจริง ไม่ใช่ล้างตลอดเวลา

Auto Clean มี 3 เงื่อนไขให้เลือก และมีระบบป้องกันไม่ให้ล้างถี่เกินไปจนเครื่องทำงานหนัก

  • ระยะห่างขั้นต่ำและ Cooldown — เว้นช่วงระหว่างการล้างทุกแบบ รวมถึงการล้างด้วยตนเอง
  • จำกัดจำนวนครั้งต่อชั่วโมง — กันการล้างวนซ้ำเมื่อหน่วยความจำไม่ลดลง
  • เงื่อนไขต้องคงอยู่ — ไม่ตอบสนองกับค่าที่พุ่งขึ้นชั่วขณะ
  • ข้ามเมื่อไม่มีอะไรให้ล้าง — ถ้า Standby List เล็กกว่าค่าขั้นต่ำ ระบบจะข้ามรอบนั้น

RAM Monitoring

เห็นว่า RAM ถูกใช้ไปกับอะไร

RAMFLOW ใช้นิยามเดียวกับ Task Manager จึงเทียบตัวเลขกันได้ทันที

  • ใช้อยู่ / พร้อมใช้ / ว่าง — ภาพรวมหน่วยความจำทั้งหมดของเครื่อง
  • แคช = Standby + Modified — ส่วนที่ Windows คืนให้โปรแกรมได้เมื่อต้องการ
  • ผลการล้างล่าสุด — ค่าที่วัดจริงก่อนและหลังล้าง ไม่ใช่ตัวเลขประมาณ

การล้าง Standby List ไม่ได้ “เพิ่ม” RAM เพราะ Standby ถูกนับเป็นพร้อมใช้อยู่แล้ว อาจช่วยในบางกรณี เช่น เกมกระตุกขณะที่ Standby ใหญ่มากและหน่วยความจำว่างแทบไม่เหลือ RAMFLOW ไม่รับประกันว่า FPS จะเพิ่มขึ้น

Update System

อัปเดตในตัว ปลอดภัย ย้อนกลับได้

Update Center ใน RAMFLOW ตรวจเวอร์ชันใหม่จากรายการที่ผู้พัฒนาลงนามไว้ ดาวน์โหลด ตรวจสอบ และติดตั้งให้เอง

  • ตรวจลายเซ็นรายการเวอร์ชัน (ECDSA P-256) และป้องกันรายการเก่าถูกส่งซ้ำ
  • ตรวจ SHA-256 ของไฟล์ทุกครั้งก่อนติดตั้ง
  • สำรองการตั้งค่าและประวัติ ก่อนอัปเดต และย้อนกลับเวอร์ชันได้เมื่อผู้พัฒนาอนุญาต
  1. เปิดศูนย์อัปเดต → ตรวจสอบอัปเดต
  2. เลือกเวอร์ชันและอ่าน Release Notes
  3. ดาวน์โหลด (มีแถบความคืบหน้า) → ตรวจ SHA-256
  4. ติดตั้งและรีสตาร์ต → RAMFLOW ปิดและเปิดใหม่ให้เอง

พร้อมลองใช้ RAMFLOW แล้วหรือยัง
